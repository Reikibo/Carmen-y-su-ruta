# Atribuciones y componentes de terceros

- **Leaflet 1.9.4:** incluido en `dist/vendor/leaflet/`. Licencia BSD de dos cláusulas conservada en `dist/vendor/leaflet/LICENSE`. Mantener ese archivo y los avisos del componente.
- **Cartografía y datos viales:** © OpenStreetMap contributors. Datos bajo Open Database License (ODbL). Información: https://www.openstreetmap.org/copyright y https://opendatacommons.org/licenses/odbl/1-0/. Mantener la atribución visible en el mapa. La red vial incluida en `source-data/roads.osm.json.gz` y la geometría derivada deben tratarse con la atribución y las obligaciones aplicables a esos datos.
- **Teselas de OpenStreetMap:** se descargan bajo demanda del proveedor configurado. Su política de uso se encuentra en https://operations.osmfoundation.org/policies/tiles/. No añadir descarga masiva ni precarga offline; para mayor escala, seleccionar un servicio adecuado.
- **Google Fonts:** DM Sans y Manrope se cargan desde el servicio de Google Fonts. No se incluyen archivos de esas fuentes en el ZIP. Las pilas CSS tienen alternativas del sistema.
- **Imágenes de referencia:** proporcionadas por el usuario para este proyecto; se conservan con ese propósito. Esta entrega no atribuye derechos adicionales sobre esas imágenes ni declara carácter oficial del servicio.

El código propio se entrega como material editable del proyecto. Este archivo no añade una licencia general nueva al código ni sustituye las licencias de sus componentes.
